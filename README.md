# Balbi Joias

Site em português para avaliação de ouro, joias e relógios, consulta de serviços e atendimento pelo WhatsApp.

**Site:** https://arthurcdag.github.io/balbi-joias/

## Estrutura

- `index.html`: conteúdo e estrutura.
- `styles.css`: apresentação e adaptação ao celular.
- `app.js`: menu, avaliação, revisão da mensagem e diálogo de privacidade.
- `assets/`: fotografias locais.
- `FONTES.md`: referências das informações e imagens.

Site estático, sem instalação de dependências. Abra `index.html` ou execute `python -m http.server 4173` nesta pasta.

## Publicação

GitHub Pages configurado para a raiz da branch `main`. Novas alterações nessa branch são publicadas automaticamente. `.nojekyll` mantém a entrega dos arquivos estáticos.

## Atendimento

Os botões de contato abrem diretamente o WhatsApp **+55 21 96725-0075**, com mensagens específicas para avaliação, compra, conserto ou penhor. Os links funcionam sem JavaScript e sem preencher o formulário.

O formulário continua disponível para quem deseja preparar uma mensagem com mais detalhes. Nenhum link ou formulário envia mensagens automaticamente, cria cadastro ou confirma agendamentos. O visitante toca em enviar no WhatsApp. Um chatbot de atendimento ainda não está conectado a este site ou número.

Informações comerciais consultadas no site de referência em 23/09/2026. Fotografias das categorias são ilustrativas; não representam estoque disponível. Não há preços ou depoimentos inventados. Consulte `FONTES.md`.

## Verificação

Layout revisado em celular, tablet e computador. Menu, categorias, formulário, geração do link do WhatsApp, edição da mensagem, FAQ e privacidade foram verificados. O código opcional de WebMCP permite preparar o assunto sem enviar mensagem.
